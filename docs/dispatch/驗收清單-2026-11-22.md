# 使用者驗收清單（正式站 1.27.28，2026-11-22）

> **用途**：未結 Issue 逐張「怎麼驗」。正式站：https://derliang.github.io/exam-affairs-helper/ ；驗收通過就在該 Issue 關單（Issue 一律由使用者關，調度員與測試員不關）。
> **事實來源**：`docs/todo.md` 狀態表與 `docs/qa/ledger.md`；本表只是把它們改寫成操作步驟。開啟 Issue 張數以 `gh issue list --state open` 為準（2026-11-22 查得 18 張）。
> **資料**：全部用假資料（例如班名溫、良、恭，名字「測試溫01」），**不要用真實名單**。需要建一份學測與一份分科的模擬考，各有 3 個班（含理組與文組）即可。
> **寬度**：標「375」「768」「1280」的，用瀏覽器開發者工具的裝置模式，或把視窗縮到該寬度。

## 先做一次的準備

1. 開正式站，頁尾確認版號 1.27.28。
2. 共用設定 → 班級資料：建高中部 3 個班（溫＝理組、良＝理組、恭＝理組），共用設定 → 教室清單：每班一間班級教室，另加 1 間預備教室。
3. 建一場學測模擬考與一場分科模擬考，匯入含上述班級的假名單（可用站內「匯出名單」產生範本再改）。
