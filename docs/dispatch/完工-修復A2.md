**邊距取 6mm 的理由**（照派工要求寫明）：一般雷射與噴墨印表機四周不可列印區約 4～5mm（各廠牌不同，部分噴墨下緣更大），Word 邊界設太小時也會跳出「邊界超出可列印範圍」提示；取 6mm 留約 1mm 餘裕。頁尾也在可列印區內（離紙邊 6mm）。這不是查單一機型規格得到的數字，**請驗收員用學校實際印表機印一張確認**。

## 四、我替你決定的事
1. **邊距 6mm**（左右上；頁尾離紙邊 6mm、本文下邊界 13mm），理由見一。改回：`LABEL_EDGE_MM`、`LABEL_FOOTER_MM`、`LABEL_BOTTOM_MM`。
2. **注意事項字級下限 B4 10pt、A3 13pt**：放不下時先用下限字，再縮格子，讓格子縮得最少（B4 深位 7 縮到 39.5mm，約為紙高÷7 的 78%）。改回：`LABEL_NOTE_PT`。
3. **深位 ≤5 不縮格子**：格高仍是紙高÷7，只有放不下才縮（使用者說「稍微縮小」）。
4. **對位測試頁不跟著改**：它是整張紙÷7 的參考格線，不是標籤實際位置；要不要改成新的格線，留給設計員或使用者決定。
5. **畫面說明文字**改成由程式算出的數字（34.0mm 等），避免寫死的「35.7×50.4」與實際不符。
6. 版號用 **1.26.4**（1.26.3 已被 PR #399 使用），決定編號用 **D136**（D135 已被使用）。
