## 二、呼叫方式（K3 下載閘門通過後）

```ts
import { produceMakeupFiles, produceMakeupPrintHtml } from '../export/makeupFiles';
import { loadFonts } from '../export/fontLoader';

const { fonts } = await loadFonts();
const out = await produceMakeupFiles(
  { title: '115 學年第一學期補考', settings, roster, plan, schedule, entries, outputs },  // outputs 傳 K3 檢核過的那一份
  { fonts, generatedAt: new Date().toISOString() /* , dayId, kinds */ },
);
out.files        // [{ kind: 'O-1'|'O-2'|'O-3'|'O-3t'|'O-4'|'O-5'|'O-7', name, docx }]
out.readback     // 交給 runMakeupChecks 的 C-14（不含 O-5，見下）
out.produced     // 交給 C-15
out.verification // 每份檔回讀與排程的逐項比對；out.ok=false 不得交付
produceMakeupPrintHtml(input, 'O-4', { generatedAt })  // PDF：回傳 { name, html, verification }，由瀏覽器列印成 PDF
```

- **C-14 的完整流程**：`runMakeupChecks({ …, readback: out.readback, produced: out.produced, currentVersion })`。C-14 紅燈要擋交付；K1 的閘門把 C-14 紅列為禁止下載、待執行不擋，所以 **`out.ok === false` 時請 K3 擋交付**（回讀不符＝紅）。
- **回讀怎麼驗**（`verification.problems`）：①總人次＝排程；②各卷人數＝排程（O-1、O-3、O-4）；③頁尾版本碼＝`makeupVersion`，頁尾「總人次」＝本批總人次；④O-2 印出的離場時間集合＝排程的離場時間；其他檔不得印排程沒有的離場時間；⑤O-4 每列卷數＝科目數、表尾統計＝名單點出的人數；⑥O-5 有人沒座位即不符。
- **O-5 不進 C-14**：座位表點的是「座位數」不是人次，放進 `readback` 會造成 C-14 假紅燈；仍有自己的 `verification`。

## 三、各文件做法與暫定

| 文件 | 做法 |
|---|---|
| O-1 備卷 | 每卷（年級＋科目）× 考日時段 × 教室 × 份數，人數只在每卷第一列；合計列＝份數合計；另行通知科目寫在表頭說明 |
| O-2 考程表 | A4 橫式（D123）；群組 × 時段，每格「時間、科目 N 人次（教室人數）」；提前開考另列一列（教室、人數、共幾人次、最早離場）；監考老師空欄列；注意事項寫離場時間 |
| O-3 公告 | 每班一頁；公告版只有學號、不印姓名；導師存參版學號欄換姓名，行數相同；舊班舊號（D122）；註欄寫「HH:MM 前不得離場」 |
| O-4 點名單 | 每考場每節一張；多科生一人一列（淡黃底加粗）列全部科目與卷數；**沒有「最早離場」欄**，註欄標離場時間（D124）；表尾各科統計（實到、缺考留空手寫） |
| O-5 座位表 | **表格版**：座位（第N排－深位）、舊班、舊號、學號，依班級座號。稿是方格版型，見第五節 |
| O-7 公假名單 | 序號、學號、班級、姓名、補考科目、科數、日期（欄位格式仍是暫定 U-3） |
| 依考日 | `dayId` 只產該日；檔名帶日期；此時 `readback` 為空（C-14 只比全場次），各檔 `verification` 與該日排程比對。兩日人次相加＝全場次（測試涵蓋） |

## 四、測試

```
npx tsc --noEmit
npx vitest run src/export/makeupFiles.test.ts   # 12 項（每份 Word 嵌字型，約 20 秒）
npx vitest run src/export                        # 既有輸出測試 104 項仍綠（改了表格格式型別）
```

涵蓋：多組假名單（多科生、提前開考、混班）下 7 種檔回讀全綠、C-14／C-15 綠；每位學生每一科都在回讀的點名單與公告出現（用格子，不看模型）；**刻意弄壞產出模型**（點名單少一人、備卷少一份、公告少一列、座位表缺座位）回讀一定抓到、C-14 紅；公告版沒有任何姓名、存參版行數相同；提前開考離場時間三處一致；兩考日依日下載；PDF 列印頁同樣回讀。

## 五、沒做到／需要決定（請調度員轉使用者）
