① 資料夾：找不到時的出路（G16、G24）

最高優先・會卡死G16G24
問題：資料夾被刪除、改名或移動後，存檔一直失敗，「更換資料夾」又被未存妥的變更擋下，使用者無路可走，只能重新整理而丟掉修改；而且畫面只丟出英文錯誤。
稿的做法（使用者已裁示：兩者都做，放資料夾設定頁，警告直接帶按鈕）：①資料夾設定頁新增「目前資料夾」卡片：名稱、狀態、最後存檔，下面三個動作各一句話分清楚——「更換資料夾」＝改用另一份資料（不帶舊資料）、「重新連結」＝找回原本那份（資料不變）、「搬到新位置」＝複製目前這份到空資料夾後改用（舊的不刪）。②找不到時，原本的紅色＋黃色兩條警告合成一條白話說明（講出資料夾名稱與可能原因、有幾項修改還沒存），帶「重新連結」「更換資料夾」按鈕，不顯示英文原文（收進「技術細節」）。③更換資料夾不再被未存妥的變更擋下：改成問「存到新資料夾／放棄」。④啟動時「使用上次資料夾」找不到，也在這裡就講清楚，不拖到存檔才失敗。⑤瀏覽器拿不到真實路徑，畫面只用資料夾名稱，並說明這一點。

④ 標示、自習與容量（G27、G31、G23、G32）

G27G31G23G32

已被 D135／D137／D141 取代的舊說法（v2.70 標示；以現行決定為準）

「自習／不考的人不畫座位、不出座位表」（G23、G27、G31、G32 多處）已被 D135③⑤ 取代：自習生也當考生排座位，只是不印標籤，且考生與自習生不在同一間教室（D135⑥、D137）。「自習座位全程固定／考試中保留座位」被 D141 取代：自習參考座位每個時段各自排、盡量同一地點。「未參加」「全科缺考」一律叫「不參加」（D146）。現行畫面以 G36 稿 v2.68 與 DESIGN §10.26／§10.35 為準；下面各節的畫面與文字是歷史稿，不得當實作依據。

問題：表格寫「已採用系統建議（可改）」，卻沒有任何可以改的地方；只有「接近一半」才另外出現選擇鈕。稿的做法：每一列都有「標示方式」三選一的並排按鈕（✕ 標不考的人／＋ 標考的人／不標），狀態徽章寫「系統建議」或「已手動指定」，已手動指定的列有「改回系統建議」；「接近一半」併進同一欄、不再另外出現一組分開的按鈕（同一件事只在一處改）。選到人數較多的一邊，只提醒不擋（D5 原則是只標少數）。提示文字改成「每一列的『標示方式』就是可以改的地方」。

每題第一項是稿目前採用的做法（建議）。你同意就不用回；不同意的說「第 N 題改選 ○○」。已經裁示過的（G16／G24 兩個都做且放資料夾設定頁、G22 班級教室不能增刪、G30 座位上限（v2.70 改為橫排、深位各 ≤ 8、總數 ≤ 56，D149②）、G23 自習算進容量——v2.70 註：「自習不畫座位」已被 D135③⑤ 取代，自習生也排座位、只是不印標籤）不再問。
1．G16／G24　資料夾找不到時，要放棄暫存的修改，要不要先把暫存內容另存成一份下載備份檔？▸ 放棄前提供「先下載備份檔」，預設勾選（建議）——多一道保險，不擋路；備份檔之後可以自己匯入或直接丟掉。缺點：多一步、多一個檔案。▹ 只警告並列出會丟掉什麼，不提供備份——最簡單；但誤按就救不回來。
2．G16　資料夾找不到時，模擬考列表區顯示什麼？▸ 顯示「讀不到資料夾，所以無法顯示模擬考」的錯誤狀態（建議）——不會讓人誤以為資料不見了，也不會出現「還沒有模擬考」的誤導。▹ 顯示上次載入的列表（灰階、唯讀）——比較有安全感，但容易讓人以為可以操作；要另外處理快取過期。
3．G24　「搬到新位置」選到的新資料夾不是空的，怎麼辦？▸ 只接受空資料夾（建議）——絕不覆蓋任何東西、規則簡單。缺點：要先自己建一個空資料夾。▹ 允許非空，只複製不存在的檔案——可搬到已有舊備份的資料夾；但容易混出新舊不一的資料。
4．G16　「更換資料夾」選到已有本 App 資料的資料夾、而且還有暫存修改時？▸ 只能「放棄」或「先下載備份再放棄」，不合併（建議）——簡單、不會把兩份資料混在一起。▹ 提供合併——看似方便，但需要衝突規則，風險高、不建議。
5．G33　「完成此步」這個詞拿掉後，目前這一步何時標成完成？▸ 按「下一步」時自動標成完成（建議）——少一個詞、少一個動作。▹ 保留獨立的「標記完成」按鈕——更明確，但回到原本「兩顆按鈕要想一下」的問題。
