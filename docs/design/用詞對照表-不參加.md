# 用詞對照表：不參加（D146；稿 v2.68～v2.69；2026-11-19）

使用者原話：「沒有所謂的缺考，只有不參加，改變用詞，缺考是指有參加但沒有應考」。給施工與審查對話對照用；規則本體在 `docs/decisions.md` D146、`DESIGN.md` §10.35。

## 一、對照

| 舊詞 | 新詞 | 說明 |
|---|---|---|
| 未參加 | 不參加 | 名冊有、考試名單沒有的人 |
| 全科缺考、N 人全科缺考 | 不參加、不參加 N 人 | 考試名單上一科都沒報的人；與上一列**合併成同一種、一個人數**（使用者問題卡） |
| 列入缺考清單，不排座／仍排座 | （拿掉） | D142 已一律排座，沒有選項 |
| 備註：全科缺考 | （拿掉） | 名單比對不再另有一張卡 |
| 原班座位表逐科「X 國 X 英…」 | 一個「X 不參加」 | 只限一科都沒報的人（使用者問題卡）；不考某一科的人照舊「X 科目」 |
| 缺考 | **不改** | 只指有報考、當天沒到：補考流程、簽到名冊「到考／缺考」欄、補考公告「無故缺考以零分計」 |
