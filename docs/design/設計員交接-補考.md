## 2. 為什麼這樣設計（重點）

1. **儀表板是靈魂（S-7）**：最上面先答兩件事——「能不能下載」（閘門）與「有沒有遺漏」（遺漏清單：為 0 時綠色大「0」＋✓；不為 0 整區紅框、逐筆列出、可就地補排）。對帳表每項寫應有／實有／差異；狀態用圖形（圓／三角／方塊）＋文字＋列左條紋三重線索。
