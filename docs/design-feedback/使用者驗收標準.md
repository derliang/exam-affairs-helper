# 使用者驗收標準（設計員逐條照原話記錄）

> 用途：使用者每次說出「驗收／輸出檔應該長什麼樣」的標準，就**照原話**記在這裡，標明來源日期。驗收員、修復員、設計員開工前必讀。
> 規則：**只記使用者說過的**，沒說的不補、不推論；來源是經調度員轉達的，註明「經調度員轉達」。公開 repo：不放真實姓名與使用者的檔案內容。
> 與具體問題的對應見 [使用者問題登記.md](使用者問題登記.md)。

## 備註

- S-02 的「不得溢出」是依使用者所見的症狀整理成標準；使用者本人尚未用一句話逐字說出「標籤不得溢出」，若日後他補充原話，請更新「使用者原話」欄。
- 後續使用者再提出標準，請**新增一列**（S-04、S-05…），不要改寫既有列；使用者推翻舊標準時，在「狀態」欄註明並保留原列。
